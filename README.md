# Мобильное приложения для домашних тренировок

**Статус:** В разработке  
**Учебная группа:** К-ИСП-241  
**Учебный год:** 2026–2027  

## 1. Описание проекта

Мобильное приложение позволяющее поддерживать самостоятельность тренировок в домашних условиях. Такой формат занятий позволяет выбирать удобное время и выполнять упражнения без необходимости посещения спортивного зала. Однако для тренировок пользователю необходимо подобрать упражнения, составить расписание и вести учет результатов.

## 5. База данных

**СУБД:** SQLite

В базе данных используются следующие сущности:
- user — профиль пользователя (цель, уровень, target_muscle, вес, рост)
- workout — тренировки (goal, level, tags с частями тела, screen_type)
- exercise — упражнения тренировки (base_reps, base_duration_sec, difficulty_scale)
- achievement — квесты/звания (kind, target_value, required_level)
- user_achievement — прогресс по достижениям пользователя
- completed_workout — история выполненных тренировок
- weight_log — записи веса по дням (UNIQUE по user_id + date)

## 7. Установка и запуск

### Требования
- Android Studio
- JDK 17
- Android SDK (minSdk 24, targetSdk 34)
- SQLite
- Эмулятор или устройство с Android 7.0+

### Установка

1. Клонировать репозиторий:

   git clone https://github.com/Dream-Team200/Mobile_programm_for_training.git

2. Открыть папку проекта в Android Studio.
3. Дождаться синхронизации Gradle, установить необходимые зависимости.
4. Запустить приложение на эмуляторе или устройстве.
