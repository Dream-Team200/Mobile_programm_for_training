# Мобильное приложения для домашних тренировок

**Статус:** В разработке  
**Учебная группа:** К-ИСП-241  
**Учебный год:** 2026–2027  

## 1. Описание проекта

Мобильное приложение позволяющее поддерживать самостоятельность тренировок в домашних условиях. Такой формат занятий позволяет выбирать удобное время и выполнять упражнения без необходимости посещения спортивного зала. Однако для тренировок пользователю необходимо подобрать упражнения, составить расписание и вести учет результатов.
